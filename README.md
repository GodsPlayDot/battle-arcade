# Battle Arcade

A unified browser arcade featuring four distinct tactical and action games:

- **Grid Combat** — isometric tactical combat with AI battle analysis.
- **Spin Arena** — momentum-based spinning-top arena battles, unlockable abilities, and post-match highlights.
- **Slime Arcade** — fast arcade combat challenges.
- **Ascension Chess** — upgraded chess strategy with an Ascension system.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Check and build

```bash
npm run check
npm run build
```
